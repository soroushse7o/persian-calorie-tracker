# راهنمای بسته‌بندی اندروید برای کافه‌بازار و مایکت (TWA و Capacitor — فاز ۳)

«کالری‌شمار روزمره» به دلیل معماری ۱۰۰٪ آفلاین، فونت خودمیزبان و عدم وابستگی به API خارجی، به سادگی در قالب اپلیکیشن اندروید (`.apk` / `.aab`) برای انتشار در **کافه‌بازار** و **مایکت** قابل بسته‌بندی است.

---

## روش اول (پیشنهادی برای حجم زیر ۱ مگابایت): Trusted Web Activity (TWA) با Bubblewrap

در این روش، کروم اندروید وب‌اپ PWA میزبانی‌شده روی دامنه شما را به صورت تمام‌صفحه بدون نوار آدرس اجرا می‌کند و به‌روزرسانی‌های وب خودکار به کاربران می‌رسد.

### مراحل اجرا:
1. نصب ابزار رسمی گوگل:
   ```bash
   npm i -g @bubblewrap/cli
   bubblewrap init --manifest=https://YOUR_DOMAIN/manifest.webmanifest
   ```
2. ساخت کلید امضای انتشار (`keystore`) و استخراج اثر انگشت SHA-256:
   ```bash
   keytool -list -v -keystore android.keystore -alias android
   ```
3. قرار دادن `package_name` و `sha256_cert_fingerprints` واقعی در فایل [`public/.well-known/assetlinks.json`](../public/.well-known/assetlinks.json) و استقرار مجدد روی دامنه تا نوار آدرس مرورگر حذف شود.
4. بیلد فایل قابل بارگذاری در پیشخوان توسعه‌دهندگان کافه‌بازار / مایکت:
   ```bash
   bubblewrap build
   ```

## روش دوم (کاملاً مستقل از دامنه و اینترنت در اولین اجرا): Capacitor

اگر می‌خواهید فایل‌های وب داخل خود APK قرار بگیرند تا حتی اولین اجرای کاربر پس از نصب از بازار/مایکت بدون اینترنت کار کند، فایل پیکربندی [`capacitor.config.json`](../capacitor.config.json) در ریشه پروژه آماده است:

```bash
VITE_SITE_URL="https://YOUR_DOMAIN" npm run build
npm install -D @capacitor/cli @capacitor/core @capacitor/android
npx cap add android
npx cap sync android
npx cap open android
```
سپس در Android Studio از منوی **Build → Generate Signed Bundle / APK** خروجی امضاشده تهیه کنید.

## یادداشت معماری درباره آنالیتیکس و همگام‌سازی ابری (فاز ۳)
- **آنالیتیکس حریم‌خصوصی‌محور:** در حال حاضر برای وفاداری صددرصدی به اصل «صفر درخواست به سرور خارجی»، هیچ اسکریپت آنالیتیکسی لود نمی‌شود و گزارش بتا به شکل محلی و داوطلبانه پیاده‌سازی شده است. در صورت نیاز واقعی در آینده، تنها از ابزار بدون کوکی خودمیزبان روی همان دامنه (با به‌روزرسانی صادقانه متن حریم خصوصی و CSP) استفاده شود.
- **همگام‌سازی ابری رمزنگاری‌شده (E2EE Sync):** تا زمانی که خروجی/ورودی JSON (همراه با ادغام هوشمند) نیاز کاربران را پوشش می‌دهد، پیچیدگی احراز هویت و سرور اضافه نشده است. در صورت درخواست پرتکرار کاربران در بتا، همگام‌سازی اختیاری با کلید رمزنگاری سمت کلاینت (`Web Crypto API AES-GCM`) پیشنهاد می‌شود.
